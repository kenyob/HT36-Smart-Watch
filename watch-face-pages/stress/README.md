# Images — Stress

We cannot capture the watch screen or a baked-in face bitmap over Bluetooth. Fill this folder from one of:

1. **Browser replica** — a PNG of the Control-Page watch twin for this item (what we render from live state).
2. **Your photos** — drop in photos you take of the watch showing this screen/face.
3. **The face file** — once we fetch it from the UTE cloud (by id) or the app cache, a rendered preview.

Name files clearly, e.g. `replica.png`, `photo-01.jpg`, `cloud-preview.png`.
